## Current Notebook

### NumPy — Student Performance Analysis

The first notebook uses a small, synthetic student-marks dataset to practice NumPy through question-based exercises. Each exercise is written in English, followed by a concise code solution and its notebook output.

Topics include:
- Creating and inspecting NumPy arrays
- Array shape, dimensions, data types, and validation
- Maximum, minimum, mean, median, and standard deviation
- Student-wise and subject-wise calculations
- Boolean masking and filtering
- Pass percentage and ranking
- Indexing, slicing, broadcasting, and outlier exploration

## Setup

Install Jupyter Notebook and NumPy:

```bash
python -m pip install notebook numpy
```

Start Jupyter:

```bash
jupyter notebook
```

Open the relevant `.ipynb` file and use **Run All** to execute the notebook from top to bottom.

## Learning Approach

- Learn concepts by solving focused questions.
- Keep code solutions short and readable.
- Use notebook outputs to verify results.
- Add new notebooks as each library is learned.
- Use synthetic or appropriately licensed datasets for practice.
